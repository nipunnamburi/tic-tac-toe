# Tic-Tac-Toe Web App

A responsive, interactive Tic-Tac-Toe web application built with HTML, CSS, and Vanilla JavaScript. Features solo play (vs CPU) and local 2-player mode.

## Project Structure
- `index.html` — Main HTML structure
- `styles.css` — Styling and animations
- `index.js` — Game logic and interactivity
- `images/` — SVG icons and assets

## How to Run
Simply open `index.html` in any web browser, or run:
```bash
open index.html
```
